# Examples

Smart Battery Pilot controls the battery through four scripts you write for
your hardware (see [Control scripts](../configuration.md#3-control-scripts)).
These pages show complete, working setups:

* [BYD Battery-Box Premium HVM + Fronius Gen24 (Modbus TCP)](byd-fronius-gen24.md)
* [Zendure SolarFlow 2400 AC+ (AC-coupled, separate PV inverter)](zendure-solarflow-ac-plus.md)

Running a different battery or inverter? Copy the
[template](https://github.com/cygnusb/ha-smart-battery-pilot/blob/main/docs/examples/TEMPLATE.md),
describe your setup and open a pull request.
